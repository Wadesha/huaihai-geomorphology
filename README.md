# 淮海地貌现场手册

一份可以带去实地的淮海地貌指南：把淮海常见的九类营力写在原理层，
把 26 处现存地点写成实例层，每一处都按同一条线索讲清楚——
**到哪看、看什么、背后的原理、现场怎么确认**。

范围是淮海四片：苏北、皖北、鲁南、豫东，即淮海经济区的核心地带。
同系列另有全国版：[../geomorphology-field-guide](../geomorphology-field-guide)。

## 这一版改了什么（重构要点）

1. **实例页重新组织为四段**：`到哪看，看什么` / `背后的原理` / `现场怎么确认` / `来源`。
   每个点位先写怎么到、在哪儿站定、什么时间或条件去最合适，紧接着写到了那里该看什么、
   拿什么当凭据；原理部分按过程链一段段讲开，不再是一句结论。
2. **全站不再罗列实测数据**。原来的「实测数据」「这些数字在说什么」「争议与口径」三个板块
   已取消，正文不出现面积、长度、高程、速率、数量这类数值；只保留地名与必要的历史年月，
   用来说明先后关系。判断一处地貌靠的是现象、接触关系与空间组合，不是记住几个数。
4. **原理视图重写**：每一类营力都写清过程怎么走、控制变量是什么、现场靠什么辨认，
   并指向淮海境内的对应实例。
5. 自检脚本随之重写：新增「实例正文不得出现阿拉伯数字」与「点位完整度 / 描述长度」两类检查。

## 版式原则（重要）

**单页标签式：顶排一排短名卡片（实例 / 原理 / 判定 / 时间轴 / 来源），
点哪张出现哪块内容；「实例」下还有第二排 26 处地点的短名卡片，点哪张出现哪一处的完整内容。**

正文以连续散文（大段文字）呈现，不用表格、统计块、步骤条、标签块、侧栏与列表；
导航卡片、标题层级与来源链接保留。`validate.py` 会自动检查散文约束与卡片结构，
出现 `STRUCTURED` 命中即视为不合格。

正文段落统一首行缩进，阅读栏宽 900 px；明暗两套主题跟随系统并可手动切换。
路由基于 hash：`#c/<slug> / #prins / #field / #time / #srcs`，默认落在「实例」的第一处，
实例深链为 `#c/<slug>`（如 `#c/sishui-quanlin`）。

## 站点结构

全部内容在 `docs/index.html` 一个文件里，按五个视图组织：

**原理**先给四条底层框架——内力与外力、成因与形态与年代、规模等级与地域分带、时间是隐藏变量——
再逐类展开九类营力：过程怎么走、控制变量是什么、现场怎么认、淮海到哪看。

**实例**是核心：一排 26 张地点短名卡片 + 各自的完整内容。
单处实例固定四段——到哪看（点位 / 怎么到 / 何时去 / 朝哪看）、看什么（可辨识的现象与凭据）、
背后的原理（成因机制链，一段一段展开）、现场怎么确认（判据与易混淆对照）。

**判定**摊开 6 组淮海高发的易混淆地貌，给出通用观察顺序、最小工具集，以及这套方法的边界。

**时间轴**把 17 个时间锚点按先后排开，每个锚点后接一句按营力分别措辞的短评，
并说明怎么读这条时间轴（次序不等于等间隔）。

**来源**把 68 条来源按实例分列，并交代使用边界。

苏北 9 处：洪泽湖、废黄河（黄河故道）、盐城黄海湿地与辐射沙洲、徐州贾汪潘安湖、骆马湖、
连云港云台山、秦山岛、蛎岈山（牡蛎礁）、兴化垛田。

皖北 4 处：宿州皇藏峪、淮北相山、八公山、怀远荆山峡与涂山。

鲁南 9 处：蒙阴岱崮地貌、郯城—郯庐断裂带、枣庄熊耳山与抱犊崮、临郯苍平原、

豫东 4 处：兰考—民权黄泛风沙地、商丘黄河故道与天沐湖、永城芒砀山、开封地上悬河与城摞城。

## 写作铁律

1. **写现象，不写数据** —— 正文只写位置、形态、物质、接触关系与判据；尺度数值一律不进正文。
2. **点位可执行** —— 每个点位都要能回答：怎么到、在哪儿站定、什么条件下去、朝哪看。
3. **看什么要有凭据** —— 不是「可以看到某景观」，而是「看到什么形状、什么界线、什么颜色，
   凭什么说它是这个成因」。
4. **原理讲过程** —— 写清物质基础、触发条件、过程与产物之间的因果链，不写一句式结论。
5. **判据要能排除** —— 每处实例都给出现场确认方法与最容易混淆的对照。
6. **来源必须真实** —— 引用的链接来自实际检索；发布前抽查源文核对表述。

## 重新生成与自检

```bash
python build_site.py     # site_data.py（数据） → docs/index.html（单页标签式渲染）
python validate.py       # 标签闭合、内链、纯散文约束、卡片结构、去数据化；结果写 _validate.txt
python diag_prose.py     # 点位完整度、描述长度、措辞重复、字段缺失；结果写 _diag_prose.txt
```

`site_data.py` 是纯数据（`REGION` / `AGENTS` / `FRAMES` / `CONFUSIONS` /
`FIELD_ORDER` / `FIELD_TOOLS` / `FIELD_BOUND` / `TIMELINE` / `TIMELINE_NOTE` / `CASES`），
`build_site.py` 是纯渲染。改内容只动 `site_data.py`。

构建脚本不删除 `docs/` 目录，只就地覆盖并按清单清理多余文件——本机沙箱会把
`shutil.rmtree` 改写成回收站操作并失败，不要改回去。
