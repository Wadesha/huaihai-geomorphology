# 淮海地貌现场手册

以杜恒俭 等《地貌学及第四纪地质学》为底本，把教材的营力体系**重构**为「原理层 → 实例层 → 判定层」，
并把实例范围收在**淮海地区**（苏北 · 皖北 · 鲁南 · 豫东，淮海经济区核心）。

同系列另有全国版：[../geomorphology-field-guide](../geomorphology-field-guide)。

## 版式原则（重要）

**全站不用表格、卡片、统计块、步骤条、标签块与侧栏，所有内容以连续散文（大段文字）呈现。**
导航条、标题层级与来源链接保留，但正文里不再出现任何行列式或栅格式展示。
数字仍逐条标注来源，冲突口径并列不合并。`validate.py` 会自动检查这条约束，
出现 `STRUCTURED` 命中即视为不合格。

正文段落统一首行缩进，阅读栏宽 820 px；明暗两套主题跟随系统并可手动切换。

## 站点结构

总览页 `docs/index.html` 的职责是把三层讲清楚：重构逻辑、地域格局（按苏北、皖北、鲁南、豫东四片列出全部实例，实例名即链接）、原书章节与本站模块的对应关系，以及 9 类营力各自控制什么变量、留下什么产物、对应淮海哪些实例。

原理页 `docs/principles.html` 先给四条底层框架——内力与外力、成因与形态与年代、规模等级与地域分带、时间是隐藏变量——再逐类展开 9 类营力系统，最后讲怎么用这套框架读一处具体地方。

实例部分是 `docs/cases/index.html` 加 16 个实例页。索引按地理分区和营力类别两种顺序各排一遍，方便「想看一片地方有什么」和「想追一类营力长什么样」两种读法。单个实例页固定包含七块内容：名称与一句话立意、含位置与可达性的导语、现场能看到什么、背后的原理（成因机制链）、这些数字在说什么、实测数据、争议与口径、来源。

野外判定页 `docs/field.html` 摊开 6 组淮海高发的易混淆地貌，给出通用观察顺序、测量与记录的最小工具集，以及这套方法的边界。

时间轴页 `docs/timeline.html` 把 13 个时间锚点按先后排开，每个锚点后接一句按营力分别措辞的短评，并说明年代口径的处理方式。

来源页 `docs/sources.html` 把 44 条来源按实例分列，并交代底本与使用边界。

## 16 个实例（按分区）

苏北 6 处：洪泽湖（一条河把一群小湖挤成悬在平原上的大湖）、废黄河（黄河故道，一条死去的河成了两大水系的分水岭）、盐城黄海湿地与辐射沙洲、徐州贾汪潘安湖（采煤塌陷地变成的湖）、骆马湖（断裂带里陷下去的湖盆）、连云港云台山（江苏最高峰，断块山）。

皖北 2 处：宿州皇藏峪（皖北平原上的石灰岩岛状残丘）、淮北相山（被采石「啃」过的残丘）。

鲁南 5 处：蒙阴岱崮地貌（中国第五大造型地貌）、郯城—郯庐断裂带与 1668 年大地震、枣庄熊耳山与抱犊崮、临郯苍平原（沂沭河冲积平原）、南四湖（微山湖）。

豫东 3 处：兰考—民权黄泛风沙地、商丘黄河故道与天沐湖、永城芒砀山。

## 写作铁律

1. **无源不写** —— 所有实测数字逐条标注出处，查不到来源的数字不写入。
2. **冲突并列** —— 同一指标多个数值全部并列呈现，不换算、不加权、不取单值。
3. **争议不裁** —— 学术争议只列双方论据，不作裁决。
4. **一篇一地** —— 一个页面即一个具体地点，标题用地名。
5. **不虚构来源** —— 引用的链接必须来自实际检索；发布前抽查源文复核数字。

## 重新生成与自检

```bash
python build_site.py     # site_data.py（数据） → docs/（渲染）
python validate.py       # 标签闭合、内链、纯散文约束、关键内容；结果写 _validate.txt
python diag_prose.py     # 措辞诊断：标签词重复、破折号叠用、字段缺失；结果写 _diag_prose.txt
```

`site_data.py` 是纯数据（`BOOK` / `REGION` / `AGENTS` / `REMAP` / `CASES` / `CONFUSIONS` / `TIMELINE`），
`build_site.py` 是纯渲染。改内容只动 `site_data.py`。

构建脚本不删除 `docs/` 目录，只就地覆盖并按清单清理多余文件——本机沙箱会把 `shutil.rmtree`
改写成回收站操作并失败，不要改回去。
